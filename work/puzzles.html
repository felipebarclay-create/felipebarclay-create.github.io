Context

Why it exists, what it does

Problem

A digital product studio that builds SaaS, management systems and sites for other businesses — still running without an identity or site to show for itself.

Solution

A visual system and live site built on the same product thinking the studio sells to clients — a folded-plane mark, one deliberate accent colour, and a site shipped as an actual product, not a static case study.

Origin

Puzzles is a personal Digital Product Studio project — self-directed, not an operating business. The interactive site was designed and built as a lead-generation tool, the way a real client-facing studio site would need to work.
